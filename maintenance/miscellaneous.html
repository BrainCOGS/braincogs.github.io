Miscellaneous ​

3D printing ​

Print ​

  1. Export the design from your CAD software as an STL file, making sure to select the units.
  2. Open the STL file in PreForm, use the orientation tool and generate support structures as needed.
  3. Make sure the build platform is clean and seated correctly. Insert the resin tank and resin cartridge properly, making sure the tap is open.
  4. Upload the print.
  5. The printer will tell you if any component is missing and prompt you if it needs leveling. Follow its instructions.
  6. Once the print is finished, remove the build platform and close the cover so the uncured resin in the tank isn't exposed to light.

Wash ​

  1. Put on gloves. Remove the print from the platform with a scraper, or remove the quick-release platform by pushing both arms inward.
  2. Rinse the print with IPA using a squeeze bottle. You can use compressed air to remove resin from concealed areas.
  3. Open the Form Wash and place the print inside.
  4. Select the wash cycle for your resin and start it.
  5. Rinse off any remaining uncured resin with the squeeze bottle and let the print dry for at least 30 minutes.

Cure ​

  1. Once the print is completely dry, place it inside the Form Cure and select the appropriate curing settings, then press Start.
  2. Once curing is finished, let the print cool to room temperature to avoid warping.
  3. Take out the print and remove the supports.
  4. Sand off any remaining support marks.
